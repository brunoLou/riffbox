# mots-fr.json

Liste de mots français classés par fréquence, utilisée pour chercher des rimes (éditeur de morceau).

- Fréquences : liste « commonWords » de @zxcvbn-ts/language-fr 4.1.3 (licence MIT), elle-même
  dérivée d’OpenSubtitles 2024 via OPUS (Helsinki-NLP), sous licence ODC-BY
  (Open Data Commons Attribution License) — https://opus.nlpl.eu/
  Les données d’origine sont attribuées aux contributeurs des sous-titres et à leurs ayants droit.
- Filtrage : seuls les mots présents dans an-array-of-french-words 2.0.0 (licence MIT) sont gardés ;
  les mots de french-badwords-list 1.0.7 (licence MIT) sont retirés.
